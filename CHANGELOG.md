# Changelog

## [1.0.0] - 2026-09-02

- Native, theme-aware Omarchy overlay with instant keyboard and mouse search.
- Batched Iconify search with a bounded local cache and offline fallback.
- SVG, Iconify name, JSX, React, Vue, HTML, CSS, and Data URI output.
- Preview, favorites, recents, persistent copy mode, and SVG file saving.
- Optional reversible `Super + I`, Omarchy menu, and `glyphtap` command setup.
